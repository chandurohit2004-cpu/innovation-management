🛡️ CrimeShield AI (Web Version)
CrimeShield AI is a web-based application built using HTML, CSS, and JavaScript that helps visualize and analyze crime data. It provides interactive dashboards, crime hotspots, and basic prediction insights for better awareness and safety.

🚀 Features
📊 Interactive Dashboard – Displays crime statistics using charts
🗺️ Crime Hotspots Map – Shows high-risk areas visually
🔎 Search & Filter – Filter crimes by location, type, or date
📈 Data Visualization – Graphs like bar charts, pie charts
⚡ Responsive Design – Works on mobile and desktop
🛠️ Technologies Used
HTML5 – Structure
CSS3 – Styling & layout
JavaScript (Vanilla JS) – Logic & interactivity
Chart.js / D3.js (optional) – Data visualization
Leaflet.js / Google Maps API (optional) – Maps
